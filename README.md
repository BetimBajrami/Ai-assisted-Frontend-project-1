## About the Project

This project is a responsive website designed for a CSS group assignment for a fictitious company. The website aims to provide a user-friendly interface and support across mobile, tablet, and desktop devices.

The landing page is designed as per the client's request to keep it as close to their expectations.

## Pages

- Home: Introduces the company and its main offerings.
- Services: Provides information about the company's services.
- About: Shares information about the company.
- Contact: Provides contact information and a contact form layout.

## Technologies Used

- HTML5
- Vanilla CSS
- Flexbox
- CSS Media Queries
- Google Fonts (Roboto)
  

## Features

- Responsive layouts for mobile, tablet, and desktop.
- Shared navigation in the header and footer.
- CSS-only burger menu for smaller screens.
- Responsive images.
- Consistent typography, colors, and styling.
