# ✈️ Travel the Skies

**A responsive travel agency website · Mayerfeld Consulting Front-End Practicum**

[🌐 View the website](https://tahliajk.github.io/Ai-assisted-Frontend-project-1/pages/index.html) · [💻 View the GitHub repository](https://github.com/TahliaJK/Ai-assisted-Frontend-project-1)

## About the project

**Travel the Skies** is a website for a fictional travel agency, developed as a collaborative front-end assignment. The goal was to translate the project brief into a welcoming, easy-to-navigate experience across mobile, tablet, and desktop screens, with an emphasis on **semantic HTML, CSS Flexbox, and responsive design**.

## Pages

| Page | Description |
| --- | --- |
| [Home](pages/index.html) | Introduces the agency and highlights travel inspiration. |
| [About](pages/About.html) | Presents the agency's values and founder. |
| [Services](pages/Services.html) | Highlights city, mountain, ocean, and winter travel experiences. |
| [Contact](pages/Contact.html) | Provides agency information and a demonstration contact form. |

## Features

- Responsive page layouts built with **CSS Flexbox** and media queries.
- Consistent header navigation and footer links across the site.
- CSS-only hamburger navigation on smaller screens.
- Mobile back-to-top links for easier navigation on long pages.
- Responsive images, shared colors, and consistent typography.
- Semantic HTML landmarks, descriptive links, and accessible navigation labels.

> **Demo note:** The Contact form is for presentation purposes only; submitting messages is not enabled, and the contact details are examples.

## Built with

## Run locally

No package installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/TahliaJK/Ai-assisted-Frontend-project-1.git
   ```

2. Open the cloned folder in **Visual Studio Code**.
3. Open `pages/index.html` using the **Live Server** extension (or open the file in your browser).
4. Navigate between pages using the header or footer links.

## Responsive testing

To review the layout, use your browser's developer tools and try these example widths:

- **Mobile:** 375px
- **Tablet:** 768px
- **Desktop:** 1200px or wider

Also check navigation, image scaling, and the mobile back-to-top control when scrolling.
